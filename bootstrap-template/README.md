A simple Bootstrap 5.3 starter template for IT111 - Research.

├── assets/

└── README.md

## Usage
1. Open `index.html` in your browser (or use VS Code Live Server).
2. Use the navbar to visit Login, Sign Up, and Dashboard.
3. Put your own styles in `assets/css/style.css`. Do not edit the Bootstrap files.

## Built With
- Bootstrap 5.3.3
- Bootstrap Icons 1.11.3
